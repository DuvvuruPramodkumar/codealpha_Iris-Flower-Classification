# Iris Flower Classification

This repository contains a complete machine learning workflow for classifying Iris flower species using the classic Iris dataset.

## Project Overview

The notebook and supporting files demonstrate:
- Data loading and exploratory data analysis
- Visualization of feature distributions and relationships
- Preprocessing with feature scaling
- Training and evaluating multiple classifiers
- Comparing model performance and selecting the best model

## Included Files

- `iris_classification.ipynb` — main notebook with the full workflow
- `iris_classification_executed.ipynb` — executed notebook with results and visualizations
- `model_results.csv` — summary of model performance metrics
- `RESULTS_SUMMARY.md` — project summary and findings
- PNG visualization files for analysis and model comparison

## Models Compared

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM) with RBF kernel
- k-Nearest Neighbors (k-NN)

## Best Result

The best-performing model in this project is the SVM with RBF kernel, achieving 96.67% accuracy.
